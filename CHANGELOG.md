## 0.1.0 - 2026-10-23

First official GitHub release, under the MIT License.

- Bounded native Codex JSONL parsing and late-safe digest-only correlation.
- Four conservative exact request/failure/read/cycle observations with physical
  source-line evidence for human review.
- Owned response-ledger sums or conservative cumulative deltas, always partial
  or unavailable; no billing or measured-savings claims.
- Fixed-field text/JSON CLI, synthetic fixtures, wheel and sdist with checksums.
- Python 3.11-3.14 on Ubuntu, Windows and macOS; 12-cell manual CI matrix.
- Verified GitHub private vulnerability reporting; documented offline installation
  and synthetic positive/negative usage examples.

Limitations: opaque nested code-mode, inherited behavioral suppression,
exact-comparison false negatives, OS-capability skips and finite resource ceilings.
Sdist member payloads reproduce, but archive metadata can differ across builds.
No dashboard, cloud service, live remediation, telemetry or external inference.
